# ⚡ Community Dex — Firefox & Zen

**Sua ferramenta Pokémon para Poké Idle World.**

A **Community Dex** é uma extensão gratuita para **Firefox** e **Zen Browser**, com Pokédex, análise de IVs, Hunt Tracker, capturas e detector de Shinies em um painel moderno e personalizável.

**✅ Versão 1.5.0 assinada pela Mozilla — instalação permanente!**

### 📥 [BAIXAR COMMUNITY DEX v1.5.0 (.XPI)](https://github.com/mrooger/Community-Dex-FireFox-Zen/raw/refs/heads/main/Community-Dex-v1.5.0.xpi)

[📦 Versões e atualizações](https://github.com/mrooger/Community-Dex-FireFox-Zen/releases) · [🎮 Poké Idle World](https://poke.idleworld.online/play) · [🌐 Community Hub](https://stigalzera.com/)

## ✨ Principais recursos

| Ferramenta | Funcionalidades |
| --- | --- |
| 🧬 **Pokédex & IVs** | Atributos, raridade, potencial, tipos, fraquezas, comparação e leitura da mochila ou Mercado Global |
| ⚔️ **Hunt Tracker** | XP/h, abates/h, loot, sessões e bônus de experiência |
| 🎯 **Analisador de Capturas** | Raridade, IV, multiplicador, filtros, ordenação e melhor captura, com suporte visual a Outland |
| ✨ **Detector de Shinies** | Alertas automáticos e histórico de encontros |
| 📊 **Community LOG** | Relatórios de sessões de 24 horas, histórico diário, salvamentos manuais e exportação JSON |
| 🎥 **Stream Geral** | Indicadores compactos para acompanhar durante as lives |
| 🎨 **Personalização** | Abas configuráveis, seções recolhíveis, painel flutuante e atalho **Alt + P** |

## 🚀 Como instalar no Firefox ou Zen

1. **[Baixe o arquivo Community-Dex-v1.5.0.xpi](https://github.com/mrooger/Community-Dex-FireFox-Zen/raw/refs/heads/main/Community-Dex-v1.5.0.xpi)**.
2. Abra `about:addons` no Firefox ou Zen.
3. Clique na **engrenagem ⚙** e selecione **Instalar extensão de um arquivo**.
4. Escolha o arquivo `.xpi` baixado e confirme a instalação.
5. Abra **[Poké Idle World](https://poke.idleworld.online/play)** e utilize o **ícone flutuante** ou `Alt + P`.

**Pronto!** A extensão assinada permanece instalada ao reiniciar o navegador.

## 🔄 Atualizações

Novas versões serão disponibilizadas em **[Releases](https://github.com/mrooger/Community-Dex-FireFox-Zen/releases)**. Para atualizar uma versão distribuída pelo GitHub, instale o novo arquivo `.xpi` assinado pelo mesmo procedimento.

## 🔒 Privacidade

Estatísticas e relatórios da Community Dex são armazenados localmente no navegador. A extensão consulta os dados do jogo e serviços públicos de Pokémon e GitHub para exibir informações de espécies e verificar atualizações.
